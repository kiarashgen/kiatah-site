# Alam Kola Nefar — complete conditional assembly sequence

Open `FULL_ASSEMBLY.html` through a local HTTP server for the complete interactive
3D playback, from an empty site through all 155 source members. `index.html` is
the sequence and asset browser. `NEFAR_FULL_3D_SEQUENCE.mp4` records the same
3D timeline at 3× speed. The project preview serves both pages.

This package covers all 155 source members: 18 in the accepted earlier
checkpoint and 137 remaining source member equivalents in 80 ordered site steps.
`FULL_98_PLACEMENT_ORDER.csv` gives the empty-to-complete order shown in the
3D playback. `FULL_SEQUENCE.csv` retains the earlier accepted 18 members as
one baseline row followed by 80 site steps. The early chronological order in
`FULL_PLAYBACK.json` was recovered from retained per-task prior-member sets.
The 80 steps contain 31 checked loaded gantry lifts and 49 guided placements.
Offsite joined planar modules reduce on-site operations. The 20 narrow roof panels
use guarded exterior hand carry and a source-solid-clear guided slide.

`FULL_98_PLACEMENT_ORDER.csv` is the complete printable placement order.
`SOURCE_MEMBER_COVERAGE.csv`
maps every original member to its assembly task. `FULL_SEQUENCE.json`
retains source IDs, dependencies and operation text. `trajectories/` contains the
31 actual checked robot path records. `evidence/` holds the geometry and fixing
audits. `CELL_MODEL.json`, `geometry.json`, and `FULL_PLAYBACK.json` drive the
source-mesh robot cell and full playback. The GLB shows final geometry.
For members split across several placed pieces, the on-screen 155-member
counter advances when the last piece is installed.

The sequence is a simulated construction study. Nominal screw geometry and
collision-free paths do not establish timber/fastener capacities, robot driver
access, machine guarding, scaffold suitability, or safe manual handling.
Those require project-specific engineering and site safety review before build.
No physical construction is claimed.

The full 3D playback retains condensed archived A/B robot motion for the first
18 members, checked source-bound routes for 31 later robot lifts, and checked
straight panel slides for 20 roof placements. The other 29 guided transitions
are illustrative and identified in the viewer. It does not establish hand
motions, robot travel between jobs, tool changes or physical fastening.
`NEFAR_ASSEMBLY_30S.mp4` remains as an earlier 2D overview.
`ROBOT_MOTION_SAMPLES.json` supplies those visualization samples.
`MEMBER_ORDER_MAP.png`, `COMPUTED_ROBOT_ROUTE.png`, the five
`SEQUENCE_*.png` views and `COMPLETED_STRUCTURE.png` are technical assets.
`ROBOT_RAFTER_TRAJECTORY_8S.mp4` isolates one computed route at slower speed.
`ASSEMBLY_CHECK_LOG.csv` and `ASSEMBLY_METRICS.json` make the conditional
result and unresolved interfaces explicit for each site step.
`FIELD_REFERENCE_CONTACT_SHEET.jpg` previews the five owner-supplied gable
photos. Their exact match to the recovered CAD remains provisional;
`FIELD_REFERENCE_PROVENANCE.json` records original file hashes.
